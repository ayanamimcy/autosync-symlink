CloudDrive2

Linux 使用 inotify，Windows 使用原生目录通知，其他平台使用目录轮询。云端变化是否完整下发需实际验证；gRPC 推送额外需要 Token。后台清理默认关闭。

扫描策略与并发

12 小时为 43200 秒。关闭启动全量扫描后，首次定时扫描会等待完整周期；文件变更和手动同步仍生效。本地递归监听和轮询本身仍会读取目录，如需避免这类访问，可在高级配置将 watch_mode 设为 off，配合 CloudDrive 文件推送。挂载盘/文件线程数为 1–32；CD2 API 目录并发为 1–4，默认请求间隔 500 毫秒。API 扫描需配置有效 Token 和虚拟路径，不强制刷新全库；清理时定向刷新缺失路径。API 模式通过 CD2 HTTP 下载元数据并校验属性，不读取源挂载文件；源目录健康标记检查仍保留。元数据下载并发取 API 并发与文件线程数的较小值，并按同样间隔启动任务。

高级 JSON 配置

支持多媒体库、通知路径映射、STRM 地址前缀和清理策略。星号表示保留已有密钥。
